# Hermes Collab Test

## Overview

This project is a stress test for the **Hermes Collab Protocol** — a multi-device AI agent collaboration framework.

## Quick Start

```bash
git clone https://github.com/sekouesp/hermes-collab-test.git
cd hermes-collab-test
```

## Structure

```
src/hermes_test/   # Python core library
cli.py             # Command-line interface
tests/             # Unit tests (pytest)
config/            # TypeScript config
docs/              # Documentation (MkDocs)
.github/workflows/ # CI/CD pipelines
```

## Agents

This project is designed for multi-agent collaboration:
- **hermes** — Lead agent, full-stack coordination
- **opencode** — Lightweight coding tasks
- **codex** — Parallel issue fixing

See `.hermes-collab.md` for the full protocol manifest.
